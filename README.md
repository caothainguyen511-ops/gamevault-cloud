# GameVault Cloud

An independent cloud-gaming client interface experiment for Android.

## Design direction
GameVault uses an original "command deck" visual identity: midnight graphite surfaces, electric-lime status accents, editorial typography, a featured-play dashboard, a compact game shelf, and dedicated device/network controls. It does not reuse OpenNOW's screen layout, visual assets, or branding.

## Current status
This repository currently contains the original UI prototype. Cloud-streaming integration is a separate engineering stage and is not represented as working until it is connected and tested.
